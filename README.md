# StoreSystem — QA Pet Project

## О проекте

**StoreSystem QA** — учебный проект по ручному тестированию приложения StoreSystem.

Цель проекта — получить практический опыт тестирования приложения, научиться анализировать требования, составлять тестовую документацию, проверять API, работать с базой данных и оформлять найденные дефекты.

## Объект тестирования

StoreSystem — приложение для управления товарами, пользователями, поставщиками и складами.

В рамках проекта проводится тестирование функциональности приложения на основе требований и критериев приемки.

## Цели тестирования

- Проверка соответствия приложения требованиям.
- Выявление функциональных ошибок.
- Проверка позитивных и негативных сценариев.
- Проверка граничных значений.
- Проверка обработки некорректных данных.
- Проверка прав доступа пользователей.
- Проверка взаимодействия API с базой данных.

## Области тестирования

На текущем этапе рассматриваются следующие функциональные модули:

- Регистрация и авторизация пользователей.
- Управление пользователями.
- Управление товарами.
- Управление поставщиками.
- Управление складами.
- Управление товарами на складах.

## Инструменты

| Инструмент | Назначение |
|---|---|
| Postman | Тестирование REST API |
| PostgreSQL | Проверка данных в базе |
| Docker | Запуск приложения и его сервисов |
| Kibana | Анализ логов приложения |
| Jira | Управление тест-кейсами и дефектами |
| GitHub | Хранение тестовой документации |

## Виды тестирования

- Функциональное тестирование.
- Позитивное тестирование.
- Негативное тестирование.
- Тестирование граничных значений.
- Тестирование API.
- Тестирование прав доступа.
- Интеграционное тестирование.

## Тестовая документация

В репозитории будут размещаться:

- Тест-план.
- Чек-листы.
- Тест-кейсы.
- Баг-репорты.
- Отчёты о тестировании.
- Postman-коллекции.
- SQL-запросы для проверки данных.

## Статус проекта

Проект находится в разработке.

На текущем этапе выполняется анализ требований и подготовка тестовой документации. Далее планируется проведение тестирования API, проверка данных в БД, регистрация дефектов и подготовка отчётов о результатах тестирования.
